# 冠英如何从 Facebook 和微信视频号发现海外买家

调研日期为 2026 年 11 月 21 日。本文给出一套面向销售的发现流程，以及冠英获得账号授权后可接入的消息与表单。以马来西亚为样例市场。已核验三家公开企业的业务资料，未与企业联系，未取得冠英的平台后台权限。下文“已验证”仅指查到公开证据。

## 一、从零开始找买家

销售输入“马来西亚，商用车制动片，找车队维修部门和独立重卡维修厂”。系统先产出企业候选，再让销售核实采购权。值得检索的词是当地买家用来描述自己业务的词，例如当地维修厂常用的 lorry、workshop 或 bengkel lori。只搜 brake pad supplier / exporter，结果容易集中到卖方。

| 搜索目的 | 示例查询，可由系统组合国家、城市、语言和业务词 | 返回后要核对什么 |
|---|---|---|
| 车队自用 | `"own workshop" haulage Malaysia`、`"fleet maintenance" "Port Klang" workshop` | 自营车队、自有维修团队、维修基地；分别保存证据 |
| 独立维修厂 | `"lorry repair" "brake repair" Selangor`、`"bengkel lori" brek Johor` | 是否维修商用车，是否承接制动业务，有无对外业务入口 |
| 企业社交主页 | 公司名加 Facebook、当地城名加 truck workshop；从官网或行业目录中的 Facebook 链接反查 | 核对国家、城市、域名或门店，排除同名页、个人账号和转载号 |
| 正在提出需求的企业 | 销售在平台允许查看的行业讨论中检索 `looking for brake lining supplier`、`need quotation brake pads`，与车型或参考号组合 | 谁说的、是买还是卖、发帖日期、是否代表企业采购。有明确型号、数量或目的地时提高优先级 |
| 视频号中的海外业务账号 | 搜“马来西亚 卡车维修”“柔佛 货车修理”“东南亚 商用车配件”等，筛公开经营账号、行业创作者 | 企业经营地、自营维修或采购角色；中文内容和海外地名本身均不足以判断受众所在国 |

**可实现的检索链。** 用带商业使用授权的网页搜索 API 找企业官网和公开目录地址；核对来源允许的用途后，读取企业服务页、网点页、联系方式页。销售也可从平台内分享一条公开企业主页或录入公司名称作为起点。AI 提取字段时必须给出来源，打不开的页面标为“待核验”，无来源的推断留空。公开网页索引对 Facebook 的覆盖有限，本次仅限 Facebook 域名的搜索未直接返回目标维修厂，但从商业目录找到了其主页。搜索服务的结果存储、目录批量复用及平台自动访问权限需分别核对。[Brave Web Search API](https://api-dashboard.search.brave.com/api-reference/web/search/post) · [Meta 对自动采集的说明](https://about.fb.com/news/2021/04/how-we-combat-scraping/)

## 三、两个平台具体能给系统什么

| 入口 | 可以获取或人工记录 | 前提和限制 |
|---|---|---|
| Facebook 上的其他企业及讨论 | 销售人工发现的公司主页链接、公开业务信息、明确的企业采购信号及时间；可用公司官网交叉验证 | 自家 Page 权限仅覆盖获授权资产。通过 Graph API 读其他 Page 的公开资料或内容涉及 PPMA/PPCA 等专门能力和允许用途；不能把这类权限当成全站搜帖、导出个人联系方式的批准 |
| 冠英自己的 Facebook Page | 订阅 `feed` 接收主页相关动态通知，筛出评论；订阅 `messages` 接收发给主页的 Messenger 消息。保存渠道内消息标识、允许读取的内容、时间和上下文 | 管理员授权，将 App 订阅到正确 Page。Meta 列出 feed 订阅的 `pages_manage_metadata`、`pages_show_list`，Messenger 另需 `pages_messaging`。读取具体内容按相应权限核对 |
| Facebook Lead Ads / Instant Forms | 投放有明确业务用途的询型表单。收到 `leadgen` 通知后，用 `leadgen_id` 取回买家提交的字段，关联表单及可用的广告来源 | 要有 Page、表单、相应广告及线索访问权限；按应用使用情形完成审核。回调载荷不能代替完整表单答案。官方支持批量读取，可作补收 |
| 微信视频号找企业和合作渠道 | 销售通过搜一搜或腾讯广告互选平台发现相关经营账号或创作者，把公司或合作渠道录入工作台。内容合作产生的实际询盘再关联其来源 | 互选平台用于广告主与创作者合作。创作者可带来触达机会；粉丝数和播放量不能证明有多少海外买家。渠道伙伴单独建档 |
| 视频号入口的微信客服 | 企业账号具备入口并绑定后，客户主动进入微信客服。收到 `kf_msg_or_event` 通知后，使用 `kf/sync_msg` 和游标读取客服消息，例如文本、产品图或名片 | 核实冠英实际可用入口及客服账号托管情况。普通视频评论、原生私信与微信客服会话是不同入口，本次未查到普通企业可用的全站评论、粉丝联系方式或全量原生私信通用读取接口。未接通的互动由运营补录 |
| 腾讯广告表单 | 对有投放条件的账号，可用原生推广页等支持的表单收集客户自填字段。线索管理平台提供导出或 API 对接路径；接口资料列有 `lead_clues/get` | 仅限本广告主已有线索。视频号版位、行业准入、境外地域覆盖、国际号码支持及账号可见功能须在投放前核实；面向海外买家的表单优先提供买家实际使用的联系选项 |

## 四、把内容转为能跟进的询盘

为车队或维修厂提供一个明确交换条件：“发旧片编码或背面照片，获得冠英目录候选和待核尺寸”。Facebook 可以用英文或当地语言的内容配合表单，视频号可以选择已有海外业务受众的行业账号联动，在后台实际支持的入口接咨询。每个活动设置来源标识。平台未回传视频或帖子来源时保留为渠道级归因，不凭时间猜具体作品。

首轮收集公司名称、国家或城市、业务角色、想查询的参考号或车型、偏好联系途径。将数量、单位及照片设为可选或在会话里补齐。没有型号也能提交。把“车队自用、维修客户车辆、门店备货、转售”做成能区分业务的选项。系统保留采购意图原句和时间，销售核实采购权。登记公开企业入口、客户为本次询价提供的联系方式、是否同意后续营销三种不同状态。营销用途、保存期限和删除请求需与企业实际流程相符。

## 五、比赛实现与验收

1. **现场主动发现。** 一个“国家＋客户类型”的搜索框，通过真实搜索 API 拉取候选。用官网核对服务和地点，返回企业卡及证据。如果现场没有搜索密钥或网络不可用，提供单独标明核查日期的“已核验样例”模式。两种模式分别显示结果来源。
2. **形成销售待办。** 企业表记录域名、国家、城市、社交业务链接；证据表记录来源、日期、支持的事实；询盘表独立保存买家自述、型号、数量、单位、联系选择、消息 ID 和负责人。优先复核“业务匹配且出现近期明确采购信号”的企业，将“有维修能力但尚未询价”的企业放入拓客名单。不同平台同名用户不自动合并。
3. **能联调就接真事件。** Facebook 由管理员提供 Page 与表单授权，微信由管理员确认视频号可用的客服入口并授权测试客服账号。由测试人员分别提交一条表单、发一条客服消息。平台条件不足时，用冠英演示用的中英询型表单真实接收评委提交的数据，平台样例事件只用于演示解析，不向评委描述为已接通。无需投放真实广告来验证系统内的表单与分派逻辑。
4. **防夜间漏收。** 收到事件后先核验并持久化，再异步取详情和识别；以平台、账号、消息或线索 ID 去重，按游标或时间范围补收；失败时保留待重试状态，值班人员可见最后成功时间。客服消息、表单留资、销售自录都显示具体来源，同一企业可有多次询盘。
5. **衡量销售价值。** 对前 20 个去重候选由冠英外贸销售盲审，统计有证据的终端匹配数、销售愿意跟进数和待核实数。收到实际回复后再算采购权确认率、有效询盘率。测试集中有效询盘应全部能查到负责人和原文，重复回调不增加工单。广告试点另比较每条合格线索成本，不能用播放量代替。
